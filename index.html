About We

Saya adalah seorang aspiring programmer yang sedang membangun perjalanan saya di dunia teknologi. Saat ini saya berfokus mempelajari web development menggunakan HTML, CSS, dan JavaScript, serta Python untuk membangun berbagai project dan memahami cara kerja aplikasi dari sisi programming. Saya lebih suka belajar melalui praktik dan project nyata daripada hanya mempelajari teori. Selain mempelajari dasar-dasar web development, saya juga sedang mengeksplorasi berbagai teknologi seperti API, WebSocket, dan Git untuk meningkatkan kemampuan saya dalam membuat project yang lebih kompleks. Salah satu project yang pernah saya kerjakan adalah bot berbasis Python yang terhubung dengan Apex Legends LiveAPI dan Discord. Saya masih berada di tahap awal perjalanan sebagai programmer, tetapi saya ingin terus berkembang, membangun lebih banyak project, dan suatu hari dapat bekerja sebagai developer profesional.
